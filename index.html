~/about

Models, agents and the data behind them

I'm an AI and Data Science Researcher at Weill Cornell Medicine-Qatar in Doha. Most of my work is building AI agents and machine learning models: multi-agent systems on Claude Code and the Model Context Protocol (MCP), LLM pipelines that extract and reason over real-world documents and data, and predictive models on time-series and health data, wearables included.

My background is in building AI-driven systems end to end, from model development to deploying LLM-powered agents in production, using Python, AWS and Docker. I focus on creating models and tools that are reproducible, scalable and useful beyond a notebook.
