Claude Research Agent

A multi-agent AI research team built on Claude Code. From a single prompt, specialist agents search arXiv or PubMed, read the strongest papers in full, map trends and gaps, hold team meetings to propose research ideas, check each idea for novelty and put it through clinical and ML critic agents. Ideas are ranked by pairwise judging, the top one is tested in a sandbox on public data, and everything lands in an HTML report. Agents talk only through validated JSON files, with a check after every step.

Meeting Scheduler Agent

Autonomous Gmail-and-Calendar scheduling agent powered by the Gemini API. Classifies incoming emails into scheduling intents, books confirmed events when a proposed time is free, finds and offers open slots (with tentative holds to prevent double-booking) when asked for availability, and now handles cancellation and rescheduling of existing confirmed meetings, checking free/busy on the new time before writing so a conflict leaves the original booking untouched. Works around a discovered LLM flaw where the model would non-deterministically corrupt meeting times in prose, by having it emit a verified placeholder that Python substitutes with the guaranteed-correct value. All replies are created as Gmail drafts for manual review, never auto-sent.

  • Google Gemini API
  • Gmail API
